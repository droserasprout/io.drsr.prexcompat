# Changelog

## [1.3.0] - 2026-11-02

### Fixed

- Fixed Incode crash when passing selfie KYC (ART View Sync companion module required).

## [1.2.0] - 2026-07-17

### Changed

- Migrated from the legacy Xposed API (82) to libxposed API (101).

## [1.1.0] - 2026-07-10

### Added

- **IncodeHook** — no-ops the Incode Welcome SDK environment gate so KYC document capture no longer fails with "No se pudo validar tu identidad" on rooted/hooked devices.

## [1.0.0] - 2026-06-20

Initial release.
